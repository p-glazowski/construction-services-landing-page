# Heliora

Portfolio concept: a one-page Polish landing site for a fictional HVAC and home-energy company.

- Fictional brand, people, phone numbers, e-mail addresses, address and prices. Nothing here refers to a real business.
- Photos are free stock images from [Unsplash](https://unsplash.com) (ids in `src/assets/photos/README.md`).
- The contact form is a demo and sends nothing.

Built with Vite, React, TypeScript and plain CSS.

```
npm install
npm run dev
```
